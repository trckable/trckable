---
title: "Keyboard shortcuts"
description: "Every key in the dashboard; each can be changed and follows your account."
---

Press `?` in the dashboard for the list; every key can be changed there and follows your account.

| Key | What it does |
|---|---|
| `?` | The shortcuts list |
| `⌘K` / `Ctrl K` | The palette: Peek first, then every table, site, period and filter |
| `/` | The same palette |
| `L` | Live |
| `B` | Explore |
| `E` | Explore, on What changed |
| `A` | Create a goal, funnel or note (opens the palette on Create) |
| `S` | Switch site |
| `U` | Your menu |
| `,` | Settings |
| `Shift S` | Share |
| `R` | Replay, play or pause |
| `T` `Y` `7` `3` `9` `1` `W` `M` | On Explore: Today, Yesterday, Last 7 / 30 / 90 days, 12 months, This week, This month |
| `←` `→` | On Explore: step the period back or forward |
| `C` | On Explore: compare with the period before |
| `Esc` | Close what is open |
