# Security

trckable stores other people's analytics and payment records, so we take
reports seriously and answer them quickly.

## Reporting a vulnerability

Please report it privately through GitHub: **Security → Report a
vulnerability** on this repository. Do not open a public issue.

Tell us what you found, how to reproduce it, and what an attacker could do
with it. You will hear back within three working days, and we will keep you
updated until it is fixed. We are happy to credit you in the release notes.

## Supported versions

Security fixes go into the latest release. Self-hosters should update when a
release says it contains a security fix.

## What is in scope

The server (`server/`), the dashboard (`dashboard/`), the tracker
(`tracker/`), the `trckable` npm package (`packages/trckable/`) and the
Docker image built from `deploy/`.
